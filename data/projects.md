## FastAPI Personal Chatbot

A model-agnostic chatbot built with FastAPI that supports multiple LLM backends.

**Description**: Developed a flexible chatbot system that can work with local LLMs via Ollama or cloud-based OpenAI models. Features include streaming responses, rate limiting, and RAG (Retrieval Augmented Generation) memory using ChromaDB for context-aware conversations.

**Key Features**:

- Model-agnostic architecture supporting multiple LLM providers
- Streaming responses for real-time chat experience
- Rate limiting for API protection
- RAG memory with ChromaDB for enhanced context retrieval
- Personal data ingestion for customized responses

**Technologies**: FastAPI, Python, Ollama, OpenAI, ChromaDB, LangChain

**GitHub**: https://github.com/parajuliaashutosh/personal-bot
